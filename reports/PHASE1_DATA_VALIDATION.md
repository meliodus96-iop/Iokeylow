# Phase 1 Public Data Validation

## Primary signal data

Repository:
https://github.com/voletiramu/nse-fno-1min-data

Used release:
indices-v1.0.0

Used file:
NIFTY_5min_5yr_2021_2026.csv

April 2021–April 2026.

The repository states the data was sourced from Zerodha Kite and is provided as-is for research.

## Option-expression data

https://github.com/rajmaurya0904/bhav

Used file:
sample_data/nifty_1y_1min.xlsx

Used sheets:
Spot_1min
ATM_Options_1min

The sample covers a one-year period in the bundled workbook and was used only for an exploratory option-expression study.

## Microstructure source

Repository:
https://github.com/QuantDev-stack/TickBytes

Public samples contain:
- tick timestamps
- LTP/LTQ
- cumulative volume/OI
- total buy/sell quantity
- top-5 bid/ask depth
- option IV and Greeks

The repository says the full historical feed is a paid subscription; therefore the Phase-1 multi-year strategy results do not use it as if it were a free historical L2 archive.

## Source-selection principle

Public social media posts, Reddit discussions, YouTube explanations and GitHub projects can be used as research leads, but they are not treated as evidence of profitability unless the underlying data and tests can be independently reproduced.

No paid data was purchased for Phase 1.
